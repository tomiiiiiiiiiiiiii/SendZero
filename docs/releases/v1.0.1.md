# SendZero v1.0.1

SendZero v1.0.1 adds first-class Docker and Docker Compose support for easier self-hosting.

## Highlights

- Docker image based on Apache and PHP 8.2.
- PHP cURL support included for master-to-node communication.
- Single-node Docker Compose deployment.
- Persistent encrypted transfer storage in a named Docker volume outside the web root.
- Separate cleanup service that runs `cleanup.php` every 10 minutes.
- Automatic minimal `config.local.php` generation for a basic single-node deployment.
- Custom `config.local.php` and `nodes.php` remain supported for advanced and multi-node deployments.
- Docker-specific Apache and PHP configuration.
- New Docker deployment guide in `docs/DOCKER.md`.
- CI now validates the Compose file, builds the Docker image and performs a live container smoke test.

## Quick start

```bash
git clone https://github.com/tomiiiiiiiiiiiiii/SendZero.git
cd SendZero
docker compose up -d --build
```

Then open:

```text
http://localhost:8080
```

For a public deployment, put SendZero behind HTTPS and review `docs/DOCKER.md` and `docs/PRODUCTION.md`.

## Compatibility

This release does not change the existing manual deployment model or the SendZero transfer protocol. Existing installations can continue to run without Docker.

## Validation

The Docker changes are covered by CI that:

- validates `docker compose config`;
- builds the Docker image;
- starts a real container;
- performs an HTTP smoke test against the running application;
- runs `cleanup.php` inside the container.

The existing PHP 5.6, PHP 8.2, JavaScript syntax checks and full Git-history security audit remain enabled.

## Security

Docker support does not change the SendZero zero-access encryption model. Production use still requires appropriate TLS termination, host hardening, trusted reverse-proxy configuration where applicable, and normal operational monitoring.

SendZero has not undergone an independent security audit.
